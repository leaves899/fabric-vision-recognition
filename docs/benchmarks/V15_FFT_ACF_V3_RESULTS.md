# V1.5 FFT + ACF V3 研究记录（2026-10-13）

分支：`experiment/v15-fft-acf-v3`，由 `experiment/v15-reflectance-engine` 创建；`main`、`demo/v5/`、冻结 V4 均未改动。此分支的 `engine.py` 已切换到 `orient_v3.propose_axes`，且仍保持 `candidate_only=True`；母分支的 V2 可直接用于回退。

## 为什么修改

V2 从全图二维 FFT 峰计算候选方向，并用同一信号的 ACF 验证；由 Wiener–Khinchin 定理，ACF 是功率谱的傅里叶逆变换，二者**不是统计独立的物理纱线证据**。斜纹也会使二者一致。单看归一化 ACF 强度还有弱投影被误判为强周期的风险。

V3 的改动：

- 按频率半径对二维 FFT 做环带白化，生成两组相差 90° 的候选。
- 对每个候选方向旋转信号、按两组方向各分 5 条空间带计算 ACF 周期；检查≥3条一致、CV、谐波/半倍频冲突。
- 在原 ACF 周期强度之外要求足够的**绝对投影对比度**，防止极弱纹理投影归一化后变成高置信度周期。
- 多种候选评分接近时拒判；没有足够正交双向证据则拒判。
- 不把候选方向、周期或合成图通过率直接提升为经纬真实物理根数认证。

### 验收结论

**G2 未达标；V3 仍不能作为 V5 人工两点方向的自动替代。**

模型在合成纯正交周期数据中可以较准确且旋转稳定，但真实织物中空间纹理和交织节律与物理纱线存在混淆；V3 只比 V2 更保守，并没有证明物理准确率提高至可交付要求。降低拒判阈值虽可抬高覆盖率，却可能把错误方向重新放行，不能以此假装达到 80%。

## 后续必须完成的独立验证

至少 10 种布料、两类组织、多次手机实拍，每张具有与布料同平面的人工确认 50mm × 50mm 内框、人工真实经纬参考方向与多截线根数；按 fabric_id 划分冻结 TEST。合格候选经/纬密度 MAPE 分别≤2% 且布料级覆盖≥80%，同时记录错向率、P95、谐波二倍计数、90/180/270 旋转稳定性、RK3576 内存和端到端延迟。所有阈值仅能用 DEV 调，不能用 TEST 样本调参后再打分。

主实验与原始 V5 未合并。若后续迭代失败，恢复 `engine.py` 中一行 import 到 `orient_v2` 即可回退。
