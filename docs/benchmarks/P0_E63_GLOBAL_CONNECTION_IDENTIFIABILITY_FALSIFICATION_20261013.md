# E6.3：跨遮挡同根连接的全局可识别性反事实（2026-10-13）

## 结论

**E6.3未解决物理同根识别，但成功证伪了E6.2把“一对一全局最佳连接”作为可信轨迹的关键前提。** 在所有前向候选构成的二分图上，E6.2所谓全局最佳连接绝大多数不是结构上不可替代的。即使数学上不可替代，也**不能认证为真实物理纱线**，因为“最多连线”本身不是纱线物理定律。

样本03的正确连接 `r0004 → r0005`、错误连接 `r0004 → r0011`（用户在对照照片上逐一确认）**都能分别被强制纳入相同大小的全局最大匹配**，从而严格说明：**不添加独立于全局连线数的实体/遮挡证据，仅凭全局一对一最多连接的优化目标在原理上无法区分正确与错误。**

此处的“用户确认”保存在独立审核文件 `datasets/physical_evidence_labels/operator_confirmations/U20261013_03_E63_counterexample.json`。**只在候选图生成、数学结论计算完毕之后才读取**；它是专家观察手机RGB照片的确认，并非显微/实物独立物理真值。原人工标注不修改，A3留出不读取。

## 代码与实验方法

- `benchmark/p0_physical_connection_identifiability.py`：复用E4原相机可见短段候选，构成前向连接图。使用SciPy稀疏二分图**最大基数匹配**。
- 对任意全局解边 `e`，删除此边后重新求最大基数 `K_without_e`。仅当 `K_without_e < K_original` 时，认为该边是“所有最大基数匹配共同必需”的**图论必要边**（不是物理必要纱线）。
- 对每个E6.2候选来源短段 `s`，分别强制各个目标 `t` 成立，重新求余图最大基数加一得到 `K_forced(s,t)`；若多个目标都满足 `K_forced=K_original`，表示**数学目标本身无法区分**。
- 以上两个反事实都不使用**像素间隔阈值、颜色/形态权重、新人工正反连接标签**，输入候选图完全不变。也不依赖E5的交织周期亮暗能量捷径。
- 图片画法：绿色仅是人工标注的局部可见短段；红色是E6.2曾连上但在当前图论模型下**存在可替代最大匹配**的未决连接；黄色只表示*图论必要*、仍**不等于物理证书**。
- 合成`3×3`全部512种简单候选图穷举比对真实最大匹配数学结果，另有多前驱抢占、等基数替代、正反人工标签隔离等测试。
- E6.3并未自动产生正确的物理连接；对于存在替代解释的E6.2连接明确要求保留 `UNKNOWN`，避免把原先错误连接作为确定物理纱线输出。

## 对结果的正确解释

- 全局一对一约束能避免一段被多个来源占用；它是结构有效性的必要条件之一，不是物理身份判别器。
- 多个等基数数学解证明该**优化目标下的非唯一性**，不等于证明原始照片中完全没有其他可用的物理信息；后续仍可研究光学遮挡实体。
- 最大匹配唯一也不能反证其他可能物理连接，因为“最大连接数”假设未得到独立物理验证。
- 此数据集中只有人工可见段和人工推断同根关系，用户最新正/负例仅来自单幅手机图像人工确认；即使正确连接落入最大匹配也不是独立实物身份GT。
- 图论必要边未经过交织上下确认，不能作为经纬密度、实际交织矩阵及整根身份准确率。
- 用户正式十项参数验收目标与单根跨遮挡物理跟踪研究不是同一个验收门槛；不能混淆。

## 下一研究门槛

**先确认照片是否有足够观测量能区分两个物理假说，才值得尝试最终连接。** E5/B相位光学特征的跨布料失效和E6.2端点Lab特征打乱结果表明，不能简单以周期/颜色/距离阈值作为物理证据。后续研究应在具体交织点上审计：A/B两组可见纱线的边界端点、T形遮挡及两侧同一实体的恢复，是否确实能从原生相机照片中分辨；如果不能，给出欠采样/信息不足的拒判记录，而非优化一个错误但完整的全球网格。

对样本06尤其要注明A组真实间距在原生照片里仅约6.455像素，2倍放大只能便利视觉查看而不能新增光学信息。后续如果获得更高分辨率近拍或同布料多方向补光，可以作为**不同成像条件下的独立验证**，不要把它当成单图识别的训练参数补丁。

**阶段定位：E6.3解决了连接置信表述上的“虚假唯一性”，未解决真实单根物理纱线身份识别。**
