## 本轮目标和状态

从用户在 PR #16 分支新上传的手机照片人工局部标注出发，比较已标可见纱线短段与**方向相近、长度匹配、地点相近**的已标视觉假线。本任务**仍非独立物理纱线实体真值验证**：`APPARENT_VISIBLE_YARN` 与 `TWILL_PATTERN` 都是单幅手机照片的人工图像判读，状态 `DRAFT`；不能将光学得分解释成真实纱线概率、准确率或真实根数。

## 二、实验实现

脚本 `benchmark/p0_operator_line_audit.py` 在 E2 原图特征上加 `nearest_length_matched_twill_pairs()`：

1. 照片来自来源哈希校验的**原始相机图像**。2×标注图只通过 `original = crop_origin + zoom_coordinate/2` 转坐标，绝不以插值照片制造新像素证据。
2. 对每条绿色可见短段，以中心位置投影到黄色人工假线，在**无向夹角差不超过10°**、**最近距离不超过40个原始像素**且黄色目标整段落在已人工画出的路径内时接受配对。否则拒绝，绝不在标注路径外假造黄色线。
3. 每条配对的黄色比较窗截取为与绿色短段**相同的原图长度**，方向沿黄色标注本身。相同的16原始像素图块测量、归一化等用于两个窗口。
4. 各配对保留绿色短段原 `region_id`、对应人手同根 `group_id`、黄色长线唯一 `region_id`、中心距离、角度差、原生像素端点与完整特征差；出具结果 JSON、CSV、原图视觉卡。
5. 多个绿短段即使各自有配对，只要属于相同人工同根组，就**先在组内汇总**再计算描述性组间中位差。多次从同一条黄色长线裁剪得到的局部窗仍属于**一个假线轨迹**，不能冒充相互独立的负样本。
6. 任何缺少充分配对的数据输出 `null`/0，而不是臆造0%准确率、伪概率或真实纱线根数。
