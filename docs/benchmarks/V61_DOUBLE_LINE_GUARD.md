# V6.1 真实纱线防重复计线（Issue #7）

## 现象与原因

用户提供的织物放大图显示：同一根真实纱线可能被画上两条红色候选线。V6 的双锚点校准仅调整位置与间距，原始 V4 候选轨迹数量不变。两个已确认真实纱线的位置对齐，不代表它们之间的候选线数量与真实纱线根数相等。

必须区分：
- **真实纱距**：由人工数清两个不同、同向、已标注纱线之间的物理间隔（相邻两根 = 1）。
- **候选线间距**：V4 周期生成的虚拟网格间距，可能是实际纱距的 1/2 或 1/3，不能直接当作真实纱距。

## V6.1 实现

1. 人工标注网页新增 A/B 组的**真实纱距间隔数**和独立确认勾选；保留原先的校准纱线、第三根独立核查纱线（holdout）。
2. `benchmark/yarn_duplicate_guard.py` 的实验算法：取得两根人工确认纱线的法向间距，再除以人工真实间隔数，得到物理纱距；对 V4 轨迹间距检查 2:1 或 3:1 的近整数倍混叠。
3. 仅当已确认物理间隔，且比例、候选支持与两端纱线落位检验都通过时，选择**每个真实纱距最多一条**候选轨迹，压制重复候选。没有确认间隔、比例不可靠、轨迹支持不足等情况直接拒判。
4. 输出 `v61_duplicate_suppressed_candidate.jpg`、`v6_candidate_tracks.json` 和 `phase_diagnostic.json` 的诊断。候选 A/B 分别记录风险；未审核的组不得标记为物理纱线识别通过。
5. **冻结 V4/V5 不变**，可继续单独运行旧版，避免影响已有基线。

## 操作

```powershell
git pull origin main
python -m benchmark.manual_annotation serve
```

浏览器访问 http://127.0.0.1:8765/tools/yarn_annotator/，先选择牛仔布照片 T001 或 T004。

- 第 1、2 条校准线必须在**不同的真实物理纱线**上。
- 如果相邻两根，输入真实纱距数 `1`；两根之间有一根完整纱线，输入 `2`；以此类推。
- 只有肉眼能真正数清时勾选“逐根核对”，数不清必须留空，不允许数现有红线来反推。
- 第 3 根验收线要放在另一根真实纱线上，不得参与校准。
- 保存后提交 `datasets/annotations/drafts/*.json` 至 GitHub 供批量测试。

若已有 `v5_result.json`，从仓库根目录运行：

```powershell
python -m benchmark.phase_offset_diagnostic --id T001 --result-dir experiments/v5-manual-round1/T001
```

需要先用原有 `benchmark.run_annotated_v5` 或 `benchmark.run_annotated_v5_roi` 生成 V5 基线结果，命令参照 `docs/benchmarks/V6_YARN_POSITION_FIX.md`。

## 尚不能宣称完成的事项

- 目前已有标注仅提供两条物理纱线参考，没有独立已确认的纱距间隔数，故已保存的历史数据**不会被自动删线**；这是为了防止误删。
- 2:1 / 3:1 比例只是检测候选网格频率混叠的条件，不是证明剩余每条轨迹都处于真实纱线中心。
- 即使压制重复候选，输出仍是**候选轨迹**，不是经过独立验证的物理纱线根数；第三根独立验收与跨新布料人工位置核查未完成前，`physical_yarn_count_usable=false`。
- 检测模型是否被布料纹理带偏，需要另外验证真实纱段位置、重复检线、漏检和拒判率，不能把纱距校正的内插误差写成自动识别准确率。
