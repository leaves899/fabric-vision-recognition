# P0 E6.2：全局纱线轨迹唯一性约束与端点形态反事实审计

2026-10-13 · PR #16 · `research/physical-yarn-trajectory-3stage-20261013`

## 核心研究结论

**全局一对一能消除同一个目标可见短段被多个前驱重复占用，但尚不能识别遮挡两侧的同一根真实物理纱线。** 尤其新采集的样本03：光学形态与几何给出的全局方案不一致，且真实端点光学特征相对“打乱端点形态、保留几何”的反事实对照，没有出现稳定优势。当前不应把“全局匹配 + 光学相似度”包装成已跨布料可用的物理纱线跟踪器。

本次是纯图像结构*竞争假设审计*；输入可见短段与SAME关系均为 `DRAFT` / `PHONE_IMAGE_OPERATOR_REVIEW`；并非物理分离、显微验证或多视角核实的真值。所有未标同根关系的连接竞争者仍为**UNKNOWN，绝不是假线/不同根物理真值**。

## 一、从V5借用的机制及本实验实现

V5的`v4_transects`沿候选网格取多个横截面并严格做到**每条轨迹与同一横截线最多相交计数一次**；其输入方向由人工给定，原V4候选网格可能错落在纱缝。E6.2复用的是**每段唯一身份和多种竞争解释的约束思想**，不是把V5网格直接当真实物理纱线。

独立实现：`benchmark/p0_global_yarn_uniqueness.py` + `benchmark/tests/test_p0_global_yarn_uniqueness.py`。只在PR#16单独实验，不改V4/V5、main和人工JSON。

**输入**：原始相机图像及哈希来源验证、操作员可见短段LINE坐标、人工A1/A2/B1/B2尺度/参考方向；生成E4的所有前向短段候选（样本01 45、03 3011、06 1270）。A3**不参与**生成/选阈/排序。无需人工 `SAME_PHYSICAL_YARN` 关系即可运行主推理；人工关系仅在全部方案生成后事后对照。

**全局结构与竞争**：

1. 每个可见短段最多一个前驱、最多一个后继：把所有前向候选构造成 DAG 的二分图，使用SciPy `linear_sum_assignment` 精确求解**最大连接基数优先，其次最小预声明序位代价**的全局一对一分配。缺失图像证据不填0；任何像素/物理距离都没有从03学习绝对阈值。
2. 采用两种**事前固定、无训练权重**的候选排序：`GEOMETRIC_CONTINUITY`优先横向归一化偏移→端部方向变化→轴向间隔；`ENDPOINT_IMAGE_APPEARANCE`优先端点截面不相似→Lab颜色差→横向归一化偏移。
3. 每条全局匹配最多为**FORCED_HYPOTHESIS**：最大基数算法有意尝试连满，这可以作为*结构上限反例*，但**不能**作为纱线身份结果。只有两种策略相同的连接才列入共同结构假设，仍只为`UNKNOWN_PHYSICAL_IDENTITY`。
4. 在`u,v`局部投影中检查两条连接弦的严格几何交叉；共同候选若存在交叉则两条均弃权（`ABSTAIN`），绝不从图像交叉自动推断实际织物物理上下关系；曲率、透视和真实复杂组织会导致额外歧义，因此投影交叉仅为冲突警示。
5. 多个短段连接形成的路径仅是可视化的结构候选，**不是物理纱线根数**；单根分裂、缺失、错误同根不能凭此自动填补。人工同根关系在所有全局匹配求解后才做弱标注重合审计。
6. **独立反事实**：先把每个来源短段的几何坐标、相机尺度、节距、末端图像签名全部固定，只把目标短段的起点图像签名作7种确定性的循环平移，再逐一运行相同求解器。该实验刻意破坏端点外观对应，**不创造真实物理负样本**；测试“图像形态是否为匹配提供显著的额外信息”。平移个数不足以用于p值或统计学显著性宣称。

## 三、必须报告的反事实结果（是否真的用到了图像形态？）

保持同一个布料的每条可见段**相机原图位置、方向、线段长度、候选几何边和所有纱距数据完全不变**，只打乱目标端点的**图像形态签名**，使用同样的求解规则。

| 样本 | 真实照片端点组合：共同连接与人工同根直接重合 | 形态打乱的同类重合数 |
|---|---:|---|
| 01 | 9/9 | **9、9、9、9、9、9** |
| 03 | **8/72** | **4、9、3、4、7、6、4** |
| 06 | 无SAME可评价 | 全部不可评价（无人工SAME） |

**关键判定：** 样本01对形态打乱完全不敏感，表明此处的连接更多由几何结构驱动。样本03虽然相对某些打乱结果略好，但至少一次反事实（9）比真实端点（8）更贴近人工同根关系。结合只有13个人工同根组、人工身份未经实物独立核验，此结果**不支持当前端点Lab/截面形态特征在控制几何后拥有可靠的独立判别能力**。这不是严格随机置换显著性检验，不能得到物理同根准确率及可泛化提升率。

## 四、哪些成果真正保留

**可用作结构约束/产品基础**：
- 单个候选短段最多1个上游/下游；一对多抢占同一目标可以用全局分配消除，不引入“多次出现=多根纱线”错误；
- 竞争方案必须同时检查候选路径次序/投影交叉，不支持任意拼线；
- 与V5相容的分轨迹归档、原生照片坐标、真实A/B几何尺度与人工确认；所有不确定结果保留`UNKNOWN`；
- 两套竞争策略公开冲突和证据缺失，没有通过人为加权蒙混过关。

**现阶段不能据此认定**：
- 最大基数全局分配的75/46条连接正确；
- 样本03另外11条跨人工同根组候选就是假线；
- 2D投影交叉必然不对应物理实纱（遮挡、弯曲、不同层级都可能造成投影误读）；
- 图像亮度/颜色稳定即真实实体，或只凭两组投影网格就能恢复过/下交织拓扑；
- E6.2已经具有跨布料可复现物理单根识别准确率。所有物理指标均为 `null`。

## 五、下一步真正的研究方向（E6.3）

研究单位应从“候选线段相似度”变成**交织遮挡事件**：对每一个候选连接，找对应的B方向穿越区域，观察A方向实体边界是否先终止、另一组纱线是否在局部连续占位、遮挡后A是否重新出现。如果单幅手机原图没有足够的光学分辨率，保留`UNKNOWN`，建议同布料近距离、不同照明、正反面互证或实际物理核验，不能用透视/周期/形态阈值冒充实体真值。

E6.3应提出可证伪的**竞争连接反例**并做布料级未见样本验证，避免用01/03作为训练与测试，不能使用A3留出调参。用户已经明确：正式系统按十项参数验收，不要求未经验证地输出每个交织点准确0/1矩阵，研究不能因追求物理理想模型而把产品研发完全卡死。
