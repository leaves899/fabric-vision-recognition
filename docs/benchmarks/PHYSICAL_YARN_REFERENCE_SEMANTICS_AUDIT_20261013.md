# PHYSICAL_YARN_REFERENCE · 独立语义纠正提交
2026-10-13，经用户核实：每个两点 `segments` 标注对应**一根真实物理纱线的延伸轨迹参考**，两端属于同根真实物理纱线，中间允许交织遮挡；它**不是** `VISIBLE_YARN_SEGMENT` 的可见像素分割，也不是表面斜纹纹理。A组 `reference` / `check_same` / `holdout_same` 分别为三根**不同**真实纱线；B组 `check_cross` / `check_cross_second` 为另外两根不同真实纱线。不同标记未必相邻；使用人工确认的 `same_family_intervals` 和 `cross_family_intervals` 表示纱距间隔数。

读入时旧 `PHYSICAL_YARN_TRAJECTORY` 兼容规范化为 `PHYSICAL_YARN_REFERENCE`，保留 schema_version 1.0 与原始 `segments`、五份 JSON 的坐标/间隔数/图像SHA/时间不变。样本04无标注。经纬仍 `UNKNOWN`；2×放大不增加物理信息；无同平面5cm标尺不可换算根/cm。
