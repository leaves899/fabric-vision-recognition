# 第一组真实纱线排列：多窗口物理节距约束实验（2026-10-13）

## 方法

沿用 PR #16 及 `PHYSICAL_YARN_REFERENCE` 正式语义。每条人工两点轨迹是**一根真实物理纱线的参考路径**，可经过交织遮挡；A1、A2、A3 是三根不同的真实纱线，B 组两条是另外两根不同纱线。人工参考并非可见纱段掩膜；记录的 A1/A2 真实纱距间隔数不默认为1。

代码：`benchmark/first_yarn_lattice_evidence.py`；测试：`benchmark/tests/test_first_yarn_lattice_evidence.py`；自动回放：[Actions Run 38341868265](https://github.com/leaves899/fabric-vision-recognition/actions/runs/38341868265)；[原始图像候选叠加图+完整JSON](https://github.com/leaves899/fabric-vision-recognition/actions/runs/38341868265/artifacts/11786139953)。

1. **方向**：只用 A1 方向对照片旋转。图像多个候选轨迹上若出现一致的斜率，报告未验证的 `image_assisted_axis_candidate_deg_UNVERIFIED`；不能称完全自动物理方向识别。
2. **节距与相位**：A1、A2、`same_family_intervals` 确定名义间隔，A3完全不参与。图像可在±0.2个纱距内搜索相位；须全图分数优于原相位，且奇数/偶数观察窗一致。相位匹配可能只是斜纹，不能据此证明物理纱线。
3. **轨迹位置**：名义格点只是几何假设，每点需在9个独立观察窗中具备脊线和双侧边界证据，局部倾斜使用直线去趋势后的残差检测。输出照片原生2×坐标的**局部证据段**；无支持或旋转镜像填充部分禁止画成已观察到的纱线。
4. **候选根数**：`nominal_lattice_site_count_NOT_actual_yarn_count` 是模型提出的可能格点；`longitudinal_image_supported_site_count_NOT_actual_yarn_count` 是获得图像支持的格点。二者都不是物理根数。A1与A2间的人工间隔数+1是**人工已确认的区段真实纱线数量**，也不等于整幅图的自动识别根数。
5. **独立评价**：A3仅在所有图像候选和A1+A2校准完成后计算近似轨迹残差，并记录附近图像证据；A3不参与阈值、尺度、相位、方向拟合或人工真值像素化。保留 `UNKNOWN` 经纬身份，不从2×图计算根/cm。

- 03先前另一版双侧边界候选为0，而本方法找到22/33有局部支持，这种方法间冲突需要检查纹理误判，并**不能解释成准确率提升**。
- 05照片相位搜索曾提出4.686个2×像素的修正，A3残差由前一未经照片修正版本约0.050变成0.250个纱距；说明最大化照片纹理分数可能**降低物理轨迹几何一致性**。本次加入奇偶观察窗分离检验，但对这张照片仍不足以排除光学假象；不使用A3反向调节参数以免数据泄漏。
- 06人工纱距约12.9个放大像素，换回相机原图只有约6.45像素/纱距，原始分辨率及纹理混叠可能严重限制识别。不能靠插值生成新的真实细节。
- GitHub CI（38项单元测试）通过。测试覆盖A3零泄漏、90°变换、无效人工间隔拒识、光学印刷纹理负对照、原生像素有效区域、证据短段几何约束。**测试通过表示软件契约满足，不等于识别准确率达到要求。**

## 结论与后续同路线实验

这一轮已将方向参考、名义物理格距、图像局部轨迹候选、区段人工已确认根数与整图候选格点区分开来；解决了部分几何/软件层面的重复线和镜像边界伪证据，但仍没有证实全部真实纱线。

下一步仍在原路线中，针对05/06做**纱线外观不一致/低原生分辨率**诊断：检查是否由照片局部交织遮挡、染色差异、纤维边界断续造成证据不足，并用独立局部真实纱线正负例检验图像峰究竟是斜纹还是实际物理纱线。不能用人工 A3 结果调参，不得把五张开发照片当独立跨布料测试集。
