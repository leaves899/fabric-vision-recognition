# Step 0 / Benchmark 框架 — 范围与验收

**阶段：**普通手机正反面兼容方案；不依赖透射图和认证 Camera Profile；本 PR 不修改 `demo/v5/` 或冻结 V4。

## 交付范围

1. 空数据模板 `datasets/manifest.csv`、`datasets/ground_truth.csv`，由人员提供实际布料真值。
2. 识别不同图片的拍摄面/位置；同一布料必须属于同一 DEV / VALIDATION / TEST 划分。
3. 独立 `benchmark.dataset` 数据校验，标出缺失照片、无标定、未确认真值以及泄漏风险。
4. V5 离线结果适配器（仅消费已存在的 JSON，不模拟用户点击、不调用自动推断）。
5. `benchmark.runner` 计算两方向的 180° 无向角误差、经纬密度绝对百分比误差、P95、评估/拒评覆盖量和逐样本失败原因。
6. 标准库 `unittest` 测试 + GitHub Actions；测试均为显式的**合成测试夹具**，不代表真实准确率。

## 评价注意

- 每个指标单独统计：有真值样本数、成功评估数、拒评数，不能只展示“低误差”而隐藏拒评。
- 仅 `CONFIRMED` GT 被计入度量；如果全部未知，输出 `NOT_EVALUATED`，不会把结果写成 `0%` 错误。
- 保存的 V5 `candidate_per_cm` 允许与真实密度做**误差研究**，仍是候选值，绝不能自动升级为正式测量值。
- 原始 V5 输出校验冻结 V4 SHA，并要求实际经纬身份、人工两点确认、物理框确认后再评估对应指标。
- 真实照片缺少 5 cm 实体框时仍可分析方向和纹理，但不应产生物理经/纬密度。
- 现有样本尚未提供完整独立人工真值：**没有可声明的准确率、覆盖率或 RK3576 性能结果。**
