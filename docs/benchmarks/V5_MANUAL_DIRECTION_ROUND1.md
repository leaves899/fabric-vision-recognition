# V5 真实纱线方向验证 · Round 1

## 为什么本阶段必须有人点两点？

现有 V4/V5 只生成候选线；牛仔布斜纹条纹、格纹色带、人字纹可能误导方向检测。V5 必须接收人工在同一根**真实可见纱段**上点出的两个像素坐标。该输入将候选组 A 定向到水平参考轴，但**不是 V5 自动找到真实纱线的证据**。

本轮实验面向 45 张已收录的公开照片，重点选 T001、T004、T005、T007 牛仔/破斜纹候选，P001 做平纹对照，T002、H001、X002、U001 做结构/颜色干扰及拒判对照。用户曾限定正式产品以牛仔面料为主，因此非牛仔或过于复杂的图先当作负例挑战样本，不混入主要的牛仔性能分母。是否属于牛仔仍需人工审核，不能只靠图片文件名。

## 本地打开标注界面

从仓库根目录运行：

~~~bash
python -m pip install Pillow
python -m benchmark.manual_annotation serve
~~~

浏览器打开 http://127.0.0.1:8765/tools/yarn_annotator/ 。

选择照片，按需要放大；依次点击：

1. **V5 输入参考线**：在同一根真实纱线上选择两点，二者须至少相距原始像素 20 px；不要沿斜纹带、阴影点或条纹选择。单点坐标以图片原始像素记录。
2. **同向独立核查线**：在*另一处可见的真实纱段*选择两点。最好是不同的一根实际纱线，使它独立于步骤 1 的输入点。这样才可进一步核验候选 A 是否与另一根真实纱线方向一致。
3. **正交独立核查线**：如清晰可见，标出另一组真实纱线的两点。没有把握就不标。
4. 选择照片的人工审核用途（牛仔候选/非牛仔负例/不确定），并勾选你确实确认参考点来自同一根纱线。物理经纬身份仅在有依据时选择 WARP/WEFT 并再确认；否则 UNKNOWN。
5. 选择 OPERATOR_REVIEWED，点击保存。坐标、图片字节的 SHA256、状态和说明保存到 datasets/annotations/drafts/ID.json。无法确认的保留 DRAFT。

安全约束：服务器只在 127.0.0.1 上监听，只允许当前仓库 manifest 内的 ID，校验路径、实际尺寸、哈希、坐标和明确人工确认。**不会自动生成实物纱线标注。** 本机标注不是公开图片本身的授权转移；分享衍生图片应按原作者许可执行。

## 验证与批量测试

在仓库根目录执行：

~~~bash
python -m benchmark.manual_annotation audit
python -m unittest discover -s benchmark/tests -v
python -m benchmark.run_annotated_v5 --ids T001 --max-images 1
~~~

上述第三条需要先安装 V5 实际依赖：

~~~bash
python -m pip install -r demo/v5/requirements.txt
~~~

运行器不修改冻结 V4 源码，直接调用现有 demo/v5/v4_analysis.py（人工传入两点，不用 FFT 或默认旋转角）。按图片写出：

- experiments/v5-manual-round1/ID/v5_result.json —— V5 候选输出；
- experiments/v5-manual-round1/ID/v5_three_panel.jpg —— 原图 ROI、红绿候选线、截线交点三联证据；
- experiments/v5-manual-round1/comparison.csv —— 候选 A/B 对照*另一段*人工核查纱线的角度差；
- experiments/v5-manual-round1/summary.json —— 运行、失败和可比对的数量。

默认只处理 1 张以防高分辨率照片导致初次运行资源过大。要执行所有已完成人工确认的输入可使用 --max-images 0。**未完成人工确认时返回 NOT_EVALUATED；不会假定参考点或输出0%误差**。用户提供的输入方向不算独立 GT，因此任何角误差只是候选诊断。要形成真实产品指标仍需独立审查人和更多不同样布验证。

## 与 V1.5 / 十项参数的关系

当前只验证方向和候选网格是否偏离人工标注，优先排除“纹理主方向=纱线方向”的误判。物理经纬身份可保持 UNKNOWN，仍可测试候选 A/B 的几何轴。没有合规 5cm×5cm 实体同平面框，严禁声称真实经密、纬密（根/cm）；没有边缘分割不得宣称纱线表观粗细等级；没有人工/独立复核组织则仍是组织候选而非正式真值。V5 原始目录和冻结哈希不变。

## 首轮完成条件

形成至少 5 张人工可复核 V5 三联图与输入/核查线（优先 3 张牛仔 + 1 平纹 + 1 纹理负例），保存原图哈希、审核状态、候选方向误差及拒判/失败原因。之后针对同一图片增加 0/90/180/270 度旋转实验，并用真实其他纱段的人工检查判定误差来源；**无需等待额外照片收齐**。
