## 结果有效性裁定

**仍有效：** 原始/放大照片、人工确认的不同物理纱线身份与间隔数、0-180°两点方向角、源图哈希、坐标归属、冻结V4/V5的软件执行结果、图像亮度候选峰/边界的可复现检测数据、A1+A2人工几何节距先验，以及A3单独的近似几何检验值。方向角吻合属于对人工参考的一致性评价，并不等于自动识别成功。

**必须重新测试/不能计入独立准确率：** PR #15 贴人工连线像素拟合“真实可见纱段”纹理模型；PR #14 使用暗点/亮点连接宣称第二组真实物理纱线；任何将A1/A2**用于拟合后再用A1/A2拟合残差报告独立准确率**的输出；把规则候选线、纹理谐波/2倍周期算作实际根数；把推断轨迹到网格的像素距离算作精确可见中心线误差；用放大照片直接计算根/cm。历史文件保留，指标语义标为 `NEEDS_REEVALUATION`。

**损失函数检查：** 本次第一组研究分支执行的算法是传统滤波/峰值/边界和几何规则，不含以这批标注作为真值训练的网络损失；不得把 `PHYSICAL_YARN_REFERENCE` 路径中的像素直接设为纱线分割正样本训练 BCE/Dice。

下一阶段仍是原任务：在方向、轨迹位置、排列周期与真实根数的范围内，找出影像证据真正支持的物理纱线，特别排除斜纹图案、缝隙和颜色周期；有独立可见纱线正例、负例及物理标尺后再对实际单根数量与根/cm验收。
