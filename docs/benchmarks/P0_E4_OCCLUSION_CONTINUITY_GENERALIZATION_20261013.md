# P0-E4：跨交织遮挡同根连续性与泛化约束——第一轮（2026-10-13）

## 结论

**E4_CONTINUITY_NOT_VERIFIED；尚未证明物理纱线跨遮挡自动连接，不能宣称 G1 / P0-1 已完成。**

用户明确纠正了一个危险推断：样本03人工相邻可见短段的“间隔约15–34原始像素、横向差几像素”只是**该布料的统计观测**，绝不能转化成跨布料连接距离的经验阈值。该数据只能用于事后诊断，算法禁止据此调整准入门槛。任何归一化后的阈值若针对03调到最好，同样会过拟合。

本次代码 `benchmark/p0_occlusion_continuity.py` 选择 **候选全覆盖 + 尺度归一化多证据并列竞争 + 明确不确定**，而不是针对样本03拟合一个“真假同根”分数。

## 实际方法与防信息泄漏

1. **输入只使用**原始相机RGB像素、用户可见短线的几何起终点、旧 A1/A2 的人工确认真实纱线间隔及 B1/B2 参考方向。手工标的72条 `SAME_PHYSICAL_YARN` 关系**不进入生成候选或计算/排序**，只有在全部竞争候选冻结后作为*弱人工图像判断*进行事后对照；旧 A3 完全不参与 E4。
2. 原生相机坐标从经哈希验证的2×放大图标注，经 `camera=crop_origin+zoom/2` 精确变换。不在插值图上提取增加的细节。
3. **不使用绝对像素长度筛选连接。** 枚举同一 A 方向前后排列的全部前向连接候选，允许较长遮挡、弯曲或横向移动；之后单独记录间隔与参考纱距之比、横向偏移与参考纱距之比、端部切线旋转角。几何信息不对某个候选作硬认证。
4. 形态信息来自**相邻短段两端可见区域内部**的原始 RGB→Lab 截面；尺度随着人工确认的本地图像纱距与可见段长度一起改变，不在缺失遮挡区伪造纱线像素。输出颜色差、截面相关性的独立排名，不把它们融合成经03调权重的总分；缺失图像证据保持`null`。
5. B1/B2 仅用于计算**预计相交的B组规则格点数**。这只是粗略几何假说，不是原图独立发现的交织点，更不是验证过的“经在上/纬在上”。输出字段 `verified_physical_occlusion=false`。
6. 竞争对象是所有其他前向候选短段。它们未被人工确认属于不同根，**不可伪造负例GT**。逐维排名和Pareto诊断只检验弱人工同根关系是否受到图像证据支持；`physical_identity_probability=null`、`physical_yarn_count_accuracy=null`。
7. 采用 `physical_fabric_id` 的布料级留出评估约束：开发/研究图像01与03不能反复拆成窗随机当独立测试；真正跨布料验证须使用此前未调参的02/05/06及独立人工/实物核对。

### 不依赖固定像素阈值 != 泛化通过

端点截面依然有`采样窗口=局部纱距/可见线段长度的一定比例`这类无量纲设计选择。它们没有按03优化，但也**尚未在另一块有可靠同根局部标注的布料验证**；比例规则只是一个合理起点，不是泛化保证。不同颜色、材质、弹性、曲率、拍摄光照仍可能使端部形态证据不稳定。

### 各个固定、未调权的单项竞争证据（人工关系事后核对）

| 单项排序依据（越小越优） | 样本01：人工连接排首位 | 样本03：人工连接排首位 |
|---|---:|---:|
| 纵向间隔/已确认纱距 | 9/9 | 3/72 |
| 横向错位/已确认纱距 | 3/9 | 33/72 |
| 两端切线角度变化 | 1/9 | 2/72 |
| 端部可见像素Lab颜色差 | 2/9 | 2/72 |
| 端部可见像素亮度截面不相似度 | 2/9 | 3/72 |

**真正值得关注的是形态证据远弱于简单几何。** 在03，横向连续性在人工同根对照里常见，但颜色与截面相似度单独几乎无法使已标同根连接胜过所有竞争候选。换布料时把“横向差几像素”当唯一准则更危险；只用颜色也无法解决实际组织纹理混淆。

这不是在验证另一张布料上的错误连接率：非SAME候选大多未标注，不得自动设为不同根；所有短段源于同一照片的人为图像判读，缺少物理独立真值。

## 交织拓扑目前的实际缺口

目前只计算**B纱线规则格点的预测交点**。尚未证明照片上在该处实际发生遮挡，也没有独立识别“消失/恢复”“哪根浮在上面”的光学证据；这些不能从A/B几何投影自动得到。尤其普通手机原图可能分辨率不足，双侧边界、亮暗纹理和色线均可能伪造交织线索。

**E5合理下一步**：在未见布料中，对每个竞争连接比较交叉位置两侧的端部实体特征；另外直接检测照片中B方向浮长覆盖A方向的局部证据（或输出`UNKNOWN`）。采用同一套事先冻结的无量纲候选/多证据逻辑进行跨布料盲验证和反例检查，不基于03的像素距离、方向或现有SAME关系选择阈值。必要时增加实物核实或不同照明照片才有真正物理身份GT。
