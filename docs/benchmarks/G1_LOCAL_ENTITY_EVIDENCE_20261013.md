# G1 局部实体形态、遮挡拓扑与竞争假设实验（2026-10-13）

## 结论

**G1_NOT_EVALUATED**。

本轮找到了一个需要人工复核的候选信号：用 A1/A2 校准的局部截面形态，在未参与特征权重或阈值选择的 `U20261013_02`、`05`、`06` 上，A3 邻近的 A 族实体假设得分均高于半相位间隙假设，分差依次为 `+0.0230`、`+0.0889`、`+0.0915`。但是：

1. 这些“间隙”仍是算法生成的竞争假设，没有独立人工确认，不能直接作为负例真值；
2. 面对斜纹表面纹理竞争项，三张独立布料相对最强负项的分差只有 `+0.0206`、`-0.0167`、`+0.0093`；
3. 三张都没有达到预先固定的 `实体分数 >= 0.48`、`相对最强竞争项分差 >= 0.10`，且整组 A 族格点相对半相位组的中位数分差还须 `>= 0.20` 才能排除错误周期；
4. A3 是一根真实物理纱线的近似延伸参考，可穿越遮挡，不是连续可见纱线像素或精确中心线真值。

因此当前证据可以优先否决部分半相位间隙，却**不能可靠否决斜纹纹理误检**，也不能计算准确率、误检率或漏检率。按照 G1 验收规则，不能宣布 `G1_PASS`。

- `U20261013_04` 没有人工审核标注，不进入评价。

## 方法与现有算法的区别

`benchmark/local_entity_competition.py` 不调用也不修改冻结 V4/V5。它不是继续调 FFT、ACF、全局脊线周期或候选网格相位，而是对三类互斥解释做同尺度局部比较：

1. **A 族物理纱线假设**：由 A1/A2 和人工间隔数给出名义路径；路径仍是候选，不是实际根数。
2. **半相位间隙假设**：在相邻名义 A 族路径中间生成，专门检验“中心落在缝隙”的错误解释。
3. **斜纹表面纹理假设**：在排除 A/B 方向后，从原图梯度方向直方图提出最强对角表面轴；它只用于竞争，不被当作纱线方向。

固定局部证据包括：双侧反向边界、表观宽度稳定性、沿线可见窗连续性、轴向相干性、A1/A2 校准的明暗极性、A1/A2 校准的截面形态相似度，以及在 B 族交点前后“消失后于同一横向位置恢复”的遮挡拓扑。所有竞争项采用相同评分流程；斜纹项也实际计算交点证据，不能因为“未计算拓扑”而被人为判负。

### 目前有用与无用的证据

- **候选有用：A1/A2 校准的局部截面形态 + 明暗极性。** 在三个独立布料 A3 邻域内都把名义物理路径排在半相位间隙之前；这个一致性值得做人工负例审核。
- **不足以单独判别：双侧边界。** 间隙边缘、白色浮长和斜纹亮带都能形成一对反向梯度。
- **不足以单独判别：表观宽度和沿线连续性。** 低原始像素节距时宽度量化不稳定；斜纹带在局部窗口里反而可能更连续。
- **尚无稳定增益：交织点遮挡拓扑。** 当前照片可见交点的局部 A/B 优势变化弱，且 A3 路径可跨遮挡；它可解释局部中断，但没有独立击败斜纹竞争项。
- **只是纹理响应：对角梯度峰、周期峰、规则格点数。** 这些只负责提出竞争解释，不构成物理纱线身份。

## 独立人工审核方式与最小待确认图块

审核者先不要打开 machine role key。依次查看 `02`、`05`、`06` 的 `blind_review_sheet.jpg`，按 `independent_review_form.csv` 填  写：

1. `physical_class` 只能选 `YARN / GAP / TWILL / UNCERTAIN`；看不清必须选 `UNCERTAIN`。
2. 单独回答是否看到双侧实体边界、是否在交织遮挡后回到同一实体轴；不要依据黄线或算法分数猜类别。
3. 至少由一名未参与特征选择的审核者完成；如要形成正式误检/漏检率，建议两名审核者独立填写并解决分歧。
4. 只有审核确认 A3 邻近图块为可见真实纱线正例、另外两个图块确为间隙/斜纹负例后，这一组三分类才能进入混淆矩阵；`UNCERTAIN` 不进入准确率分母。

最小审核范围是独立布料的 9 个盲图块（每张 3 个）；`01/03` 的 6 个图块只用于方法诊断，不能升级成独立验证。
