# P0-E6 / V5启发实验：多截线一致性是否能改善真实纱线与视觉假线的分辨（2026-10-13）

## 研究对象

本轮从现存V5源码提取**可迁移机制**，并完成真实照片原像素对照，而**不是把冻结V4/V5候选网格当成单根物理纱线真值**。V5算法/模型未被改动。

**V5源码事实：**
- `demo/v5/reference_direction.py`：方向由操作者对同一根推断物理纱线的两点确认后输入；不是自动定位真正纱线。
- `demo/v5/v4_adapter.py`：仅作I/O封装与人工旋转参数传递，调用冻结V4；检查V4 SHA256，不修改其检测内核。
- `demo/v5/v4_analysis.py::v4_transects`：沿主轴选3个横向截线，逐轨迹计算截线交点、统计相邻间隔和稳定性，单条轨迹与同一截线只计一次。该交点是**V4候选线相交**，不是实物纱线的证据。
- `benchmark/yarn_phase_anchor.py`, `yarn_pitch_calibration.py`, `yarn_duplicate_guard.py`（后续V6）：展示位置相位校正、两根不同人工实纱参考的候选间距校正以及重复候选的抑制；有人工来源和拒绝不可靠校准的守卫。属于*候选几何管理*，不能证明遮挡处上下交织、颜色纹理是真实纱线。
- `docs/benchmarks/V5_REVIEWED_ROUND1_RESULTS.md`, `V5_ROUND2_U001_AND_DENIM_INTAKE.md`：有些样本人工轴向接近，但候选轨迹依然可能落到纱缝、重复/漏线；方向误差小不等于单根位置正确。

**E6据此选择两个能复用但不会制造真值的原则**：
1. 对同一个人工标注局部轨迹，多截线一致性属于**一条候选的多个相关观测**，不能把5个截线当成5条独立纱线或5个正样本。
2. 与斜纹纹理进行比较时，保持**原始相机分辨率**，尽量控制方向、线段长度、物理位置；竞争假线在手机图像人工判读层级，并不等于物理确认负样本。

## 实验实现

新代码 `benchmark/p0_v5_multitransect_audit.py` 和 `benchmark/tests/test_p0_v5_multitransect_audit.py` 已接入PR#16的GitHub CI，逐张利用来源SHA确认的原始JPEG，2倍放大图仅提供坐标。

每条APPARENT_VISIBLE_YARN、TWILL_PATTERN人工LINE取5个纵向位置（线段内部15%、32.5%、50%、67.5%、85%），每个位置沿法线取覆盖一个人工确认的A组纱距的亮度截面。计算：

- **中心-双侧绝对亮暗响应**（按各截面自身强度波动归一，未强制纱线是亮的还是暗的）；
- **5个位置的亮暗极性一致比例**（允许亮/暗不同材质，评价沿线是否稳定）；
- **中心同时高于或低于两侧的比例**；
- **局部截面响应的纵向变异程度**。

截线横向的25个插值采样值只是**对原始相机像素的取样，不是25个独立光学像素**。对U06原生纱距约6.455像素的数据明确输出低采样警告。处理上每张原始图只计算一次Lab亮度图，避免在RK3576上对每段重新转换整幅照片。

03有与黄色假线近同方向、等长度、近距离配对的12条绿色段，且仅来自2个人工同根组并对应一条黄色假线。统计**先在同根组内合并、再比较组级中位值**；01和06缺少同方向近距离假线可比集合，不能直接比较真假绝对中位数声称准确率。标注依然是`DRAFT/PHONE_IMAGE_OPERATOR_REVIEW`。

**研究观察**：
- 增加多截线以后，“有中心亮暗峰”“双侧边界更强”依旧不是可靠的实体判据：03黄色假线的亮暗响应在未匹配统计中更强；等长近邻配对的双侧同号峰差仍为0。
- **沿线亮暗极性一致性与响应稳定性**可能比“仅看某一个截线是否有峰”更值得研究。03的等长近邻配对中绿色在极性一致性上高+0.15、在响应波动上低0.43119。但此比较本质上仍只有2个关联组和1条假线，远不足以认定跨布料泛化。
- 06的未匹配轨迹也呈现绿色更稳定、黄色波动更大，但**黄色线方向平均比A1差约33°**，这可能是方向捷径；06纱距仅6.455原生像素又限制截面可靠性。因此不能拿06的表面差异宣称独立成功。
- 合成测试用**单纯计算机绘制的亮线（没有任何真实纱线）**也可以触发很强的局部中心峰，直接否证“5截线亮暗响应高就是真实物理纱线”的解释。

## 决策与 E6.2 建议

**保留**：V5的多截线/每轨迹只计一次、独立假设比对、真实原像素尺度保真、相位/重复检测守卫；尤其值得跟进“沿线可见区域的*形态稳定性*”作为**弱证据或者竞争否决项**。

**不迁移**：冻结V4网格自动沿填充空隙、仅依据两人工标注线把候选轨迹直接升级成实纱、从测试布料选择最佳亮暗极性和阈值、把预计B格点当成实际遮挡。

**下一项真正接近跨遮挡的试验**：从人工可见短段构造有向竞争关系图，联合使用“同一目标不得由两个互斥来源占用”“空间相邻实纱应在遮挡前后尽量保持排列次序（允许局部扭转和分辨率模糊）”“两个端点可见区域的多截线极性/形态是否一致”等条件，产生多个互斥全局连接假设，并保留`UNKNOWN`。标注SAME关系必须仍只作事后对照，未标不同根不升级成负真值。切忌按样本03固定15–34px距离或局部亮暗阈值做硬过滤。

要证明**物理交织实体**，依然需要交织处局部可见性切换/上下遮挡独立证据，以及在未参与方法设计的布料上盲验证。当前绝对不是“已经解决泛化”。
