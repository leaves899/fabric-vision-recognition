## 结果判断

1. 原方法的高置信度错向风险确实存在：T001/T004/T007 的最大 FFT 方向与人工纱段约错 31°–37°；低 patch dispersion 并不代表真实经纬线。
2. 新双证据算法能够把这些危险的方向候选主动拒判，但 **25/66 的出候选率远小于 G2 80% 覆盖率门槛**，且 U001 新候选仍有 9.606° 误差，所以方向部分没有通过正式验收。
3. 66 张公开图片均缺少经纬计量所需的物理确认。计量路径不能依赖未知像素尺度、虚构框尺寸或由程序自己生成的“真值”；密度误差达标与否仍是 **NOT_EVALUATED**。
4. 视觉证据叠加图只绘制全局两轴假设和操作员的原始参考段，不等于每根纱线对应的中心线标注。

## GOAL 决定

**G2 = NOT_PASSED**。按 G2 原契约，至少需要 10 块互相独立的布料，覆盖两类以上组织，照片带与布同平面的 5cm × 5cm 标定内框，人工量得可靠四角、真实经纬方向以及多个截线上的真实经/纬根数；由不同人员复核，并在独立 TEST 上统计误差和覆盖率。已有 66 张 DEV 图不能承担这种验收，也不应把人工两点输入的 V5 输出误写成自动定向成功。

以后只在新建的独立 TEST 上验证，开发集的失败案例不能逐张调参并回报“泛化成功”。
