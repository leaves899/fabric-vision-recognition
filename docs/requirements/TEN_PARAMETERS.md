# 十项识别/辅助确认参数（业务验收范围）

| 编号 | 参数 | V5 当前状态 | 后续目标 |
|---|---|---|---|
| 01 | 经向方向与角度 | 人工参考轴 + V4 双族候选，身份需确认 | 可验证自动候选、人工兜底 |
| 02 | 纬向方向与角度 | 第二族候选，身份需确认 | 同上 |
| 03 | 经纱排列状态 | 候选轨迹、间距等统计 | 正式排列状态/不规则性定义 |
| 04 | 纬纱排列状态 | 候选轨迹、间距等统计 | 同上 |
| 05 | 经纱粗细候选等级 | 无可靠边缘分割，UNAVAILABLE | 表观宽度 P10/P50/P90→候选等级；非纱支 |
| 06 | 纬纱粗细候选等级 | 同上 | 同上 |
| 07 | 组织结构候选 | 人工确认，自动识别尚未验证 | 平纹、2/1/3/1左右斜、破斜纹、缎纹、变化组织等 |
| 08 | 经密 | 有 5cm 框时可得候选根/cm；需人工核验 | 多截线真值对照后正式计量 |
| 09 | 纬密 | 同上 | 同上 |
| 10 | 表面纹理与色系 | 独立的色系/纹理统计候选 | 保留，不参与伪经纬定向 |

### 规则

- 本项目允许逐项状态：`CANDIDATE`（候选）、`CONFIRMED`（人工确认）、`UNAVAILABLE`（证据不足）、`NOT_EVALUATED`（尚未评估）；不得把候选值标作正式真值。
- 5cm×5cm 实体框内侧真实尺寸 50mm×50mm，框与布同平面。标定缺失时不得输出确定性的物理密度或绝对宽度。
- V5 人工点击两点必须取自**同一根真实纱线同一段清晰可见纱段**，方向身份（经/纬）是独立确认信息。
- 经纬密度比是额外公式字段，前提是已确认经密和纬密且纬密不为 0。
- 花度沿用人工录入，不算第 11 项自动参数。
- 正反面普通手机照片允许不严格配准；双光源标准采集属于拟新增可选模式。
