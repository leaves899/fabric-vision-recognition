# 5.1 图像识别部分——特性设计与实验验证（冻结 V4）

**适用范围：**《鑫兰工艺研发辅助系统特性设计》第五章图片识别部分（FR-002～FR-011）；与原文件的 FR 编号、需求—输入—处理逻辑—输出写法保持一致。  
**版本：** V4 技术基线适配稿（2026-10-12）  
**设计目标：**识别或辅助确认截图确定的十项参数：经向、纬向、经纱排列、纬纱排列、经纱粗细、纬纱粗细、组织结构、经密、纬密、表面纹理与色系。  
**说明：**本文为功能设计与验证实验方案，不代表十项参数已全部通过准确率验收。经纬比（FR-007）及花度（FR-009）沿用原系统规定，**不算新增的第 11、12 项图像自动识别参数**。

## 总体处理流程

**输入：**普通手机织物照片（可上传正反面，允许不严格配准）；与布料处于同一平面的实体标定框，**内侧真实尺寸为 5 cm × 5 cm**；拍摄面及人工确认信息。

**处理逻辑：**照片上传与版本管理 → 质量检查及实体内框四角确认 → 透视校正、有效 ROI 提取 → 冻结 V4 生成两族候选轨迹（A/B） → 方向、排列和截线计数 → 组织及纱线粗细辅助判断 → 独立纹理色系统计 → 人工确认、修正和版本留痕。

**输出：**十项参数的候选值、状态、证据图与来源；没有可靠依据的项目输出“需人工确认/不可计算”，不得补造数值。

## FR-002 样品图片上传与版本管理（沿用原功能）

**需求：**支持正面、反面及局部放大图片上传，保存图片版本、拍摄面、标定信息与识别关联。

**输入：**样品编号、手机照片、拍摄面、拍摄时间及备注。

**处理逻辑：**① 校验格式、大小、可解码性；② 保存原图及版本号；③ 后续裁剪、标定和识别结果与原图版本关联；④ 上传失败保留原任务，不生成无效识别数据。

**输出：**原图版本、图片元数据及处理状态。

## FR-003 图片预处理、物理标定与质量检查

**需求：**提取可信的布料分析区域，完成清晰度检查与 5 cm 物理标定，作为后续测量基础。

**输入：**当前照片、实体框内侧四角（自动候选或人工点选）、质量检测参数。

**处理逻辑：**
1. 检查模糊、遮挡、反光与曝光异常；明显不合格时提示补拍。
2. 按左上、右上、右下、左下顺序确认实体方框**内侧**四角，检查四边形合理性；角点不可确定时允许人工修正或拒绝物理标定。
3. 利用 `cv2.getPerspectiveTransform` 与 `warpPerspective` 将内框区域投影到正方形 ROI；记录单应矩阵、原始角点、标定状态和有效尺度。若采用 901×901 像素 ROI，则相邻像素间隔对应 `5/900 cm`。
4. 原始图、透视校正图与算法有效纹理掩膜分别保存。**V4 内部计算的纹理四边形不等于 5 cm 实体内框**，不能替代物理标定。特别验证透视重采样是否使 V4 尺度敏感特征失效。

**输出：**原图及校正图、内角坐标、单应矩阵、质量提示、`cm_per_px` 与标定状态。无有效标定时，物理密度和宽度不出确定值。

## FR-004 图片识别空态保护

**需求：**没有本次合格图片时，所有图片识别字段为空，不得从历史样品或当前主样品预填为本次图像检测结果。

**输入：**本次图片状态、有效 ROI、任务状态。

**处理逻辑：**未上传或质量不合格时禁用识别；历史识别值只允许作为明确标注来源的参考，不混入本次算法输出。

**输出：**识别空态、拦截原因及可继续操作提示。

## FR-005 经纬方向、排列/组织与纱线粗细候选识别

**需求：**从当前图像形成经、纬两族方向、排列、粗细和组织的可视候选，并对不可靠结果标记“需人工确认”。

**输入：**FR-003 的有效 ROI、冻结 V4 训练数据及参数、人工指定的经纬身份（如有）。

**处理逻辑：**
1. **特征提取：**V4 采用 OpenCV 将图像转换到 Lab 颜色空间，使用多个高斯尺度的亮度/色度响应、位移差分和二阶变化构建局部特征。
2. **双族候选识别：**使用两套 LightGBM 分类器产生概率响应图；通过平滑、行列响应剖面、峰值检测及候选间距估计产生两族位置。当前冻结模型来自有限的人工掩膜训练样本，不能声称跨布料已验证。
3. **候选轨迹生成：**V4 结合周期网格约束、去重和纹理有效掩膜裁剪，输出红/绿两族候选线及三联图；统计各族候选轨迹的方向角、截线交点与间距波动。**网格补线不等于真实单根纱线检测**；不得把织物斜纹带当成真实经纬轴。
4. **经纬身份确认：**A/B 与实际经纬身份独立；无法可靠判断时由研发人员选定经向组。算法旋转配置不是自动经纬方向识别。
5. **粗细及组织候选：**粗细应依据局部纱线边界及有效尺度估计；仅有 V4 中心线时返回“不可计算”。组织候选须具有交织结构证据，当前 V4 没有可靠自动组织分类器时保留人工选择及“其他/待确认”。业务候选包括平纹、2/1 左右斜纹、3/1 左右斜纹、破斜纹、缎纹、变化组织等；不能仅凭斜纹表面带判断左右斜纹。

**输出：**两组候选角度及排列状态、三联轨迹证据；粗细和组织候选及其可计算状态；需人工确认清单。不得把候选线数量写成已确认纱线根数。

## FR-006 经密与纬密识别

**需求：**在物理尺度有效且候选计数经过核对的条件下，识别或辅助计算经密、纬密。

**输入：**FR-003 校准尺度、FR-005 A/B 候选轨迹及经纬身份、人工修正计数（如有）。

**处理逻辑：**
1. 沿与目标纱线方向近似垂直的截线进行**多位置**计数；对 V4 候选轨迹采用折线与截线相交统计，记录交点、长度、重复或遗漏疑点。
2. 将每条有效截线的候选数量 `Nᵢ` 除以真实截线长度 `Lᵢ(cm)`，计算候选密度 `Dᵢ=Nᵢ/Lᵢ`，汇总中位数、范围及一致性。一次截线上的同根局部重复响应需要去重。
3. 在没有人工逐根核对之前，结果只能标记“**候选根/cm、需人工确认**”；缺少经纬身份或 5 cm 标定时不得输出正式经/纬物理密度。
4. 允许人工确认或修正，算法原始值与人工值分层保存。

**输出：**经密/纬密候选值、单位、截线证据、差异范围及确认状态；无标定则提供不可计算原因。

## FR-007 经纬比计算（原系统配套功能，不属于十项图像识别范围）

**需求：**对**已确认**的经密、纬密，按既定统一口径计算经纬比。

**输入：**FR-006 的有效确认值或人工合法补录值。

**处理逻辑：**统一单位并检查纬密非零后计算 `经纬比=经密/纬密`；算法候选不得直接进入确定性公式结果，人工修正留痕。

**输出：**经纬比系统计算值、计算口径及数据来源；数据不足时为空。

## FR-008 表面纹理与色系候选识别

**需求：**提取与经纬纱线方向独立的表面纹理和色彩特征。

**输入：**FR-003 的有效 ROI、颜色分析配置及人工确认信息。

**处理逻辑：**对图像进行颜色聚类形成主色候选；使用灰度梯度/Sobel 等统计纹理方向、对比度与纹理强弱。**纹理方向只能用于参数10，不可回填为经纬方向真值**；光照、阴影与白平衡可能影响结果。当前 Demo 已实现主色聚类、纹理方向及对比度视觉统计；纹理粗细等级仍需进一步开发。

**输出：**纹理方向和强度候选、主色系及其视觉证据、需人工确认状态；纹理粗细等级不足时不填造识别值。

## FR-009 花度人工录入/确认（保留原要求）

**需求：**花度不作为十项图片自动识别参数。

**输入：**样品花度字段、研发人员录入值。

**处理逻辑：**保留人工录入及来源；缺失时为空，不由 V4 预测或由历史记录冒充。

**输出：**花度人工确认值及来源标识。

## FR-010 识别结果人工确认、修正与补录

**需求：**研发人员逐项确认 FR-005～FR-008 候选值，修正异常并补录图像无法可靠获取的参数。

**输入：**十项参数的候选值与证据图、人工确认或补录数据。

**处理逻辑：**展示原图、V4 两族候选轨迹、截线交点和算法说明；对每项执行“确认/修正/待确认/不可计算”操作。未经确认的关键物理量不得作为后续工艺推算的确定输入。

**输出：**按字段保存的识别原值、确认值、状态与来源。

## FR-011 识别修正留痕

**需求：**保证算法结果与人工修正可追溯。

**输入：**识别版本、原始候选、人工改动信息。

**处理逻辑：**保留旧版本，记录修改人员、时间、原因与前后值；重新识别创建新版本，不覆盖历史事实。

**输出：**识别与人工修正历史。

## 附录 A  冻结 V4 实验验证设计

| 实验项 | 数据/操作 | 检查内容 | 验收依据 |
|---|---|---|---|
| E01 代码回归 | 冻结 V4 + 既有三张回归图 | 模型文件哈希、候选数、轨迹、三联图重现 | 与冻结输出一致；不等于识别准确 |
| E02 方框标定 | 5 cm 实体方框照片 + 人工四角真值 | 角点、透视与截线 cm 长度；错误标定阻断 | 实物尺寸/人工核验记录 |
| E03 旋转 | 同图 0/90/180/270° 与 ±5/10/20° | 逆旋转后轨迹、方向轴、密度候选一致性 | 图像坐标统一后比较，不强行假定自动通过 |
| E04 抗误识 | 平纹/斜纹/破斜纹、不同颜色及光照 | 斜纹带被误当纱线、暗点颜色敏感、串线、边角漏检 | 人工真实纱段/截线标注 |
| E05 经纬密度 | 有内框样品，多截线人工真实计数 | 候选交点与真实纱线根数差异、根/cm 误差 | 独立人工计数真值；无真值不报准确率 |
| E06 粗细/组织 | 有边界和组织类型真值的新布料 | 粗细候选等级、组织分类混淆矩阵及拒判 | 逐块布料人工或测量真值 |
| E07 泛化 | 按布料 ID 划分，正反面/旋转不跨集合 | 未见布料表现、类别覆盖、失败原因 | 按布料独立统计，禁止测试集调参 |
| E08 系统联调 | 上传→标定→候选→确认→保存/导出 | 空态、异常、重试、字段来源及版本 | FR-002～FR-011 逐项检查 |
| E09 设备性能 | RK3576 4GB + 前端同时运行 | 内存峰值、耗时、CPU/NPU 可用性 | 实机测量；桌面成功不能代替 |

**已知基线：**此前冻结 V4 的三张开发回归图，A/B 候选数分别为 **73/53、80/61、80/75**；另三张未完整标定的新图测试为 **57/77、77/69、86/72**。这些均是**候选轨迹数**，不是经/纬真实根数。新三图的 90° 倍数姿态归一化已验证几何一致性，但**没有证明物理纱线准确率与任意角度泛化**。

**实验数据要求：**记录 `fabric_id`、照片版本、拍摄面、原图、5 cm 内框四角、经纬人工身份、计数截线真值、组织类别、算法版本、参数配置及运行日志。样本不足时如实说明，不编造准确率；任何未获得的人工真值标记 `NOT_EVALUATED`。**正式误差阈值和运行时延指标尚未由双方确认，不能在本设计中伪称已定稿。**

**现阶段结论：**冻结 V4 可作为候选轨迹识别基线；纹理/色系已具备视觉候选统计；纱线粗细与组织的可靠自动识别、物理密度真值校验、自动内框检测及 RK3576 部署仍需完成。本设计的验收口径为 **十项业务参数 + 人工确认 + 真实证据 + 可追溯状态**，不是生成整图单根纱线完整轨迹。
