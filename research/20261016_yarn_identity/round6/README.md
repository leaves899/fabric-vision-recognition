# V6 五图独立纱线关联：局部物理证据与竞争否决（实验原型）

**重要限制：该程序没有纱线身份的人工真值，不能将输出的临时轨迹编号视作已确认的独立物理纱线。**

## 实验目的

将上一轮几何检测出的两组短线，变成**包含局部物理证据和竞争假设检查的纱线轨迹候选**；不再按照纱线颜色识别和分组。仅处理局部实拍区域；暂不输出真实根数、根/cm或织物组织的确定类别。

## 输入和算法

- 5张原始高质量实拍照片（`inputs/photo_01.jpg` 至 `photo_05.jpg`），没有输入旧版叠加图。
- 原始RGB照片仅转换成灰度，不使用蓝/白色像素阈值来识别两组纱线。
- 细尺度梯度张量提出两组**方向候选**，不预先设成0°或90°。
- 方向对齐后，通过带状物体两侧的相反符号梯度生成**局部带状结构候选**。目前它们也可能来自纱线边缘、空隙或交织纹理，尚不能判为真实纱线。
- 对每个候选连接同时计算：局部中心偏移、间隙长度、宽度一致性、间隙内双侧梯度支持度、另一组交叉片段邻近情况。
- 使用全局一对一分配、互斥连接和**次优竞争候选差距**拒绝歧义关联。若无足够证据不强行连线。
- 对于短间隙且有双侧边界支持的连接，标为 `locally_observed_continuity_candidate`；只具有相容遮挡几何关系的，标为 `occlusion_consistent_unverified`。
- 对中心区域额外进行**平移3px/5px、σ=2模糊、缩小到75%再放大**测试，取3项扰动全通过的保守子集。
- 也记录灰度反相、90°和180°旋转的一致性，注意这些变换部分由算法构造具有协变性，不能独立证明物理正确性。

## 运行

```bash
pip install -r requirements.txt
python test_v6.py
python run_v6.py --multi-roi
python stress_v6.py
python build_review.py
```

`run_v6.py --multi-roi`对每张照片进行中心、左上、右下共三个512×512裁剪；`stress_v6.py`对每张**中央裁剪**做复检（不是15个区域）。

## 结果概览

| 照片 | 中央ROI初选连接 | 3种非平凡扰动全部复现 | 其中短间隙且有边界证据 | 其中遮挡相容但未验证 |
|:--|--:|--:|--:|--:|
| photo_01 | 37 | 3 | 2 | 1 |
| photo_02 | 24 | 4 | 1 | 3 |
| photo_03 | 30 | 1 | 0 | 1 |
| photo_04 | 30 | 5 | 1 | 4 |
| photo_05 | 47 | 16 | 1 | 15 |
| 总计 | **168** | **29** | **5** | **24** |

这里的“连接”只是两个局部结构的关联假设，不等于一根新的独立纱线；多个连接可能位于同一条候选轨迹。测试反映当前检测器对轻微模糊敏感。**无人工同根真值，不能据此计算识别准确率、召回率或真正纱线数量。**

## 结果文件

- `outputs/five_photo_audit.jpg`：五张照片中心区域，左原图、右第一轮几何连接候选。
- `outputs/five_photo_strict_consensus.jpg`：五张照片中心区域，左原图、右3/3稳定关联子集。
- `outputs/photo_XX_manual_review_sheet.jpg`：每条稳定连接逐一给出原图局部与叠加图，A、B是两端局部检测候选点，粉色虚线**不是已经存在的真实纱线**。
- `outputs/manual_review_template.csv`：29条候选的完整原图坐标与人工判断字段（`same` / `different` / `uncertain`）。
- `outputs/audit_results.json`：15个ROI的全量结构候选和连接证据。
- `outputs/transformation_audit.json`：中央5个ROI的逐连接扰动结果。
- `outputs/summary.csv`：15个ROI的方向、连接、轨迹候选汇总。

## 下一轮验收前提

1. 为每张图至少人工检查10–20条连接（包括**被拒绝的竞争连接**），标记同根、不同根、不确定；不可只标预测为正确的样本。
2. 明确可见的完整纱段的真值范围、局部交叉遮挡证据，以及同根连续性标注。
3. 基于人工真值评价关联precision/recall、跨物理纱线误连率、同根漏连率，并按不同布块划分验证集。
4. 只有通过物理身份核验后才可合并为唯一纱线ID、计算相邻纱距与根数。

说明：所有固定距离阈值只用于**当前输入分辨率的探索性候选筛选**，不是已证明可泛化的物理尺寸参数。今后应通过图像局部纱距和几何尺度归一化替代这些像素阈值。
