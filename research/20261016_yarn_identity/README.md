# 织物真实纱线与交织拓扑研究归档（2026-10-16）

> 研究性成果归档，不是可交付的织物识别模型。该分支不覆盖 main/V5。

## 输入与项目目标

普通手机拍摄真实机织物，正式使用与布料同平面的5cm×5cm实体标定框。最终识别10项：经纬方向和角度、经纬排列状态、经纬粗细候选等级、组织候选、经密、纬密、表面纹理色系。每个纱线中心必须有物理实体证据，不能把颜色条纹或斜纹周期当作真实纱线。

五张高质量照片来自用户上传的 高质量照片.rar：4张3060×4080，1张4080×3060。**本次仓库归档未上传这些二进制原图**，完整实验包留在前会话附件；如新会话没有附件，应明确索取。

## 核心事实与失败结果

- 蓝色纱线混有浅色纤维，不能由纯蓝像素掩码表示一根蓝色物理纱线。
- 局部实体边界/细尺度方向和大尺度斜纹方向不同；多尺度梯度和双侧边界可提出局部结构候选，但不证明物理纱线中心。
- V6在5张图中央ROI分别得到37、24、30、30、47条几何初选连接（共168），扰动一致性筛选后分别剩3、4、1、5、16条（共29）。稳定≠物理同根。
- 用户逐条确认前24条稳定连接均为不同根，属于误连负样本；另5条尚未核验，不得补标签。坐标在 manual_review/review_labels.csv。
- 本次人工确认集中的正确连接为0/24。该比值只对已核验子集成立，不能据此推断全部连接的召回率、总体精确率。
- 用户已知 photo_05 为3/1 Z斜纹；该真值只准用于**算法完成盲测后**比较，禁止作为组织类型、纱线连接或周期拟合的输入条件。
- 目前连接器按局部带状响应、间距、角度、对边梯度、一对一匹配和扰动稳定性连接片段；24条全部误连说明这个框架需要重新审查，不可微调阈值后自称突破。

## 下一阶段应该做什么

1. E1：人工给定真实交织点坐标和两组局部方向，算法盲判A在上/B在上/无法判断/无效点。不得提供浮沉类别或组织标签给模型。
2. 独立比较T形遮挡边界、交叉处可见表面连续性、被遮挡纱线在两侧恢复、局部纤维方向与边界梯度。颜色和阴影只作辅助。
3. 标注高质量交织点真值，保存原图局部、候选位置、支持/反对证据和是否可判定；正确率和弃判覆盖率同时统计，按不同布块分组。
4. E2：自动交织点定位，单独计算召回率与定位精确率，不与E1遮挡分类混为一谈。
5. E3：在不输入 photo_05=3/1 Z 的情况下，由局部上/下矩阵盲推1/1、2/1、3/1、缎纹、破斜纹和变化组织，未知可弃判。
6. E4：以独立检测的交织拓扑反过来审核物理同根连接，不能用周期规则生成虚假的已确认纱线。
