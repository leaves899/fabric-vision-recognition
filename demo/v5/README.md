# 织物十大参数识别 Web Demo v5（人工两点定向 + 冻结 V4）

本版只修改 **Demo 的输入、方向参考和 API 流程**，不修改冻结版 V4 检测算法。页面不再采用默认 `-13°`，不会通过 FFT、结构张量或纹理峰值自动猜测经纬方向。

## 启动

Windows：双击 `启动Demo.bat`。或者在工程目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8008
```

打开 http://127.0.0.1:8008 。首次执行 V4 较慢；之后相同 ROI 与角度会使用 `v4_cache` 中的结果。建议 Python 3.12 或 3.13。

## 核心操作

1. 上传布料照片，或加载示例照片。
2. 在照片上的模式 **「① 纱线参考方向 · 取 2 点」** 依次点击 P1、P2。两点必须来自**同一根真实纱线、同一段清晰可见的纱段**；不要沿斜纹带、黑色暗点排布或纹理方向点击。两点间原图距离必须至少 20 px。
3. 检查橙色连线是否贴合这根实际纱线，勾选「我已确认两点属于同一根真实纱线」。未完成此操作不允许运行 V4，绝无默认 -13° 回退。
4. **如照片包含 5cm × 5cm 实体内框**，切换到模式「② 实体框标定 · 取 4 角」，按 TL→TR→BR→BL 点击四个**内侧**角点。只有验证后勾选「我已核对」才能输出物理量候选。切换模式不清除已选纱线 P1、P2。
5. 可额外指定 V4 候选组 A/B 中哪组为经向（经纬身份仍单独人工确定），以及人工组织分类。
6. 开始分析。页面会同时显示人工原图参考角、校正 ROI 参考角及传入 V4 的旋转角，展示 10 项参数与三联证据图。

注意：照片不带完整框也可运行方向、排列、颜色等视觉分析，但不会输出可信的根/cm。

## 算法/坐标约定

- 用户点击点坐标使用**原始图像像素**（左上为原点，`x` 右正、`y` 下正）。
- `theta_image = (atan2(y2-y1,x2-x1) ×180/π) mod 180°` 为原图人工确认的无向纱线轴角；两点顺序交换不改变结果。
- 若指定实体框四角，先使用单应矩阵将 P1、P2 投影到 901×901 的物理标定 ROI，重新计算 `theta_roi`；无需直接沿用原图角度。
- `rotation_v4 = ((theta_roi+90) mod 180)-90`，范围 `[-90°,90°)`，作为 OpenCV `getRotationMatrix2D` 输入，使参考轴在处理后接近水平。
- 用户参考线只规定 **V4 第一候选组 A 的水平参考轴**，不是经/纬身份确认；经纬身份由“哪组为经向”单独选择。
- 两点几何确认只是用户输入可信条件，并不验证 V4 候选线是否确属真实单根纱线。90°、跨布料准确率仍需独立验收。
- 在 `v4_adapter.py` 中也已移除 `rotation_deg=-13` 的默认参数，避免无意间调用回退。

API `POST /api/analyze`：`multipart/form-data`

| 字段 | 类型 | 说明 |
|---|---|---|
| `image` | 文件 | 照片 |
| `reference_points` | JSON 数组 | 必填，例如 `[[x1,y1],[x2,y2]]` |
| `confirm_reference` | bool | 必须 `true`，由用户实际确认两点 |
| `corners` | JSON/null | 可选实体框四角 `[tl,tr,br,bl]` |
| `confirm_corners` | bool | 可选，确认后允许物理标定候选值 |
| `warp_family` | `A` / `B` / 空 | 人工指定经向组 |
| `weave_override` | 类别/空 | 人工指定组织类别 |
| `confirm_weave` | bool | 人工确认组织结果 |

JSON 字段 `manual_yarn_reference` 包含输入原图坐标、透视后坐标、原图角度、ROI 角度、V4 校正旋转角、人工确认标记；`direction_evidence` 也有上述角度摘要。

## 实际功能边界

- 参数1–4：来自冻结 V4 候选轨迹、截线交点统计，不等于真实物理纱线一一对应。
- 参数5–6：V4 不含纱线边缘分割，`UNAVAILABLE`。
- 参数7：组织分类仅支持人工确认，不能假装自动预测。
- 参数8–9：只有人工确认完整内框后才能计算**候选根/cm**，仍须人工核查候选轨迹，不等于正式经纬密度。
- 参数10：独立色系/表面纹理统计，不向 V4 提供真实经纬方向。

