# 公开织物近景样本集

**27 张真实摄影照片，保留来源原始图像文件**。用于十项织物识别功能的开发调试、算法回归和跨材质泛化评估；图片不等于带经纬身份和组织真值的标准数据集。

- 图片路径：`images/`
- 原始文件及署名/许可：[sources.json](./sources.json)
- SHA-256 文件校验：[checksums.sha256](./checksums.sha256)
- 更新脚本：`scripts/fetch_public_samples.py`；自动下载与提交由 GitHub Actions 执行。

## 采集/真值说明

**不要混淆不同层级的标签**：

- `weave_candidate` 是 Commons 文件描述或织物名称对应的**组织候选/弱标签**；不能直接作为经纬组织精确真值。破斜纹、人字纹、缎纹若缺乏组织实测，也不能推导 3/1 斜纹等规格。
- `warp_weft_identity_confirmed=false`：尚无布料物理经纬身份标注。V5 点击两点取向属于**人工辅助识别**，不是自动获得真实经向。
- `has_5cm_calibration_frame=false`：目前**所有 27 张均不包含项目规定的与布料同平面的 5×5 cm 实体框**。
- P004、P005 含毫米刻度，P006 含厘米刻度（`has_visible_scale=true`）；可作为额外参考标尺试验，但不符合项目正式采集框约束。
- S001/S002（缎纹）与 T009/T010（斜纹）来源分别注明正反面；**不保证严格同位配准**，不能作为配准/反光透光成对采集真值。T006 是**单张内外面对照图片**，不是两张对应同位照片。
- `density_ground_truth=false`：没有独立实测经密/纬密。只有尺度，不意味着可以直接用于根/cm正式验收。
- 灯芯绒表面绒条、格纹色条、斜纹带等不是可靠的真实单根纱线方向：应作为检测算法误识别的挑战样本。

## 对应十项识别目标

| 编号 | 参数 | 本组可测程度 |
|---|---|---|
| 1–2 | 经向/纬向方向与角度 | 可测试近似正交两族候选，但无身份真值 |
| 3–4 | 经纱/纬纱排列状态 | 可人工校核局部视觉效果 |
| 5–6 | 经纬纱粗细候选等级 | 可比较相对候选，不具备纱支实测真值 |
| 7 | 组织结构候选 | 可做弱标签预测与人工复核，不可自动当正式验收准确率 |
| 8–9 | 经密/纬密 | 不满足项目规定的 5 cm 框标定验收条件 |
| 10 | 表面纹理/色系 | 适合直接做初步回归与干扰测试 |

## 使用方式

```bash
python -m pip install Pillow
python scripts/fetch_public_samples.py
cd datasets/public_samples && sha256sum -c checksums.sha256
```

其中少数手机 JPG 采用 MPO（多图像 JPEG 兼容容器）编码，校验脚本接受 JPEG/MPO 并保持原始字节；可按需另生成 JPEG 兼容衍生版，不能将其宣称为未改动原图。
