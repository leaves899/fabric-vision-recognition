# shibie V0.6.3 与人工物理纱线方向的盲推理后对照

基于 2026-10-20 GitHub Actions 19-case smoke 基线（源程序未改动），读取其输出的 `summary.json`，之后单独读取仓库 `datasets/annotations/drafts/U20261013_*.json` 人工方向标注。

## 对照方法

- 标注为 `PHYSICAL_YARN_REFERENCE`，两端点属于同一根物理纱线；可跨遮挡，不是可见纱线中心线的逐像素 Ground Truth。
- `reference/check_same/holdout_same` 的双点 `atan2(dy,dx) mod 180` 中位数为第一组参考方向。
- `check_cross/check_cross_second` 同法为第二组参考方向。
- 从首次运行的 `summary.json` 独立取 `direction_a_deg/direction_b_deg`，允许两轴身份交换匹配，轴向误差 `min(|a-b|,180-|a-b|)`。
- **人工标注仅用于推理后评估**；没用于选择角度、初始化识别或给程序输入。
- 原图与标注 2x zoom 是各向同性放大与平移，线段角度保持不变。
- 本试验没有重新运行新的参数组合，因此这张表是方向误差诊断，**不是调参改进或真实中心线检测正确率**。

## 优先级与验收建议

1. P0：01 的方向被偏移近 28°，调查 Structure Tensor 候选集和方向对评分是否被表面斜纹而非实体纱线主导。
2. P0：给出候选角度、频域参考、局部纹理强度与中心线实体证据的分离审计；相关峰值不得直接冒充单根纱距真值。
3. P1：用人工标注评估方向角（不等于定位精度）；对同一布 90°、180°、不同 ROI 的盲推理一致性单独测。
4. 在至少两种独立来源实物织物以及未用于调参的样本上验收，不为提高 PASS 数量而降低门槛。
