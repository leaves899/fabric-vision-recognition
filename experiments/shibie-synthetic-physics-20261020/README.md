# 合成真实纱线身份数据：设计与限制

本目录的程序只为评估、调试 `shibie` 的物理纱线识别过程，不提供真实布料的可用精度保证。

## 使用

在仓库根目录执行：

```bash
python -m pip install -r shibie/requirements.txt
python shibie/evaluate_synthetic_physical.py
```

随后查阅 `experiments/shibie-synthetic-physics-20261020/report.md`、`synthetic_metrics.csv`、`review_sheet.jpg` 与 `visuals/` 下的双图和逐根纱线JSON。CI会自动归档整套数据。

## 原理与已完成的数据属性

- 同一合成场景含两个相互交叉的**物理纱线实体家族**。每根纱线拥有持久ID和覆盖全图的连续中心曲线，交织遮挡不会生成新的ID。
- 显式构造平纹、2/1斜纹、3/1斜纹、五枚缎纹的浮沉关系，并从同一构造几何渲染反射图和透射图；随机旋转、纱线宽度/间距扰动、摄影模糊、噪声、局部照明、光学斜向干扰。
- 真值的模拟 mm/px 是由合成器指定的数字，不代表有物理5cm标定框或相机标定。720/768像素局部图也不等同设计工位的8000×6000原生拍摄。
- 纱线GT从 `synthetic_physical_fabric.py` 产生，在评估器 `evaluate_synthetic_physical.py` 内**推理之后**读取。标注绝不能作为算法的密度范围、方向、预过滤或组织类别的输入。
- 单根检测评分不是结构张量峰的精度：程序输出曲线与合成真实中心曲线按法向投影一对一匹配，容差为模拟节距32%，角误差大于10°自动计为0。报告记录按家族的 precision/recall/F1，并保存逐像素画在透射图上的线条。
- 所有实验都必须先检验 synthetic ground truth 的一致性，再横向比较同一组合成图上的两套算法参数。

## 仍不具备的真实性

不保证真实纤维断裂/毛羽、厚度与扭转、未染色透明混纺、相机彩色滤阵、复杂镜头点扩散、纹理高光、真实纱线随机扁平变形、布料起球、严重多轴透视、手机图像多帧锐化/压缩以及实际纱线品种分布的模拟充分性。

真实数据仍是最后的否决权。合成集分数改善只能决定下一轮候选，必须在未参与调参的**真实 R/T 原图**和真实 P1/P2/P3 样本上验证，尤其防止把合成器中较规则的纱线间距规律过拟合为算法先验。

## 研发流程约束

1. 先冻结随机种子、场景参数和已知物理真值。
2. 跑原版作为 baseline，记录错误种类；再用训练场景更改一项算法参数。
3. 只能用开发场景挑参数，所有留出合成场景只做评估。
4. 再用独立真实样本作最终测试，任何真值纱距退化必须追踪；不能只看`PASS`或候选条数。
