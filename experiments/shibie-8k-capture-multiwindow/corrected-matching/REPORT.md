# 原生8K纱线物理中心：更正一对一F1评估器

所有推理结果来自已经冻结的真实8K程序运行；未修改检测出的任何中心线。

## 验收边界

本计分修复不等同于识别算法改进。新计分是物理纱线中心在一个截面的有限门内一对一位置匹配，尚未评价遮挡跨越、纱线物理ID连续性。
不能用此前存在错误配对风险的0.32F1结果判定算法优劣。
不将算法或评估器合并到main，需在更全面数据中独立核验。
