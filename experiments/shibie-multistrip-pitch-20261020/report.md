# 多截线独立物理周期实验（不合入基线）

使用原版自动预测方向，随后在不同纵向局部区域提取一维亮度/边缘能量并做跨区域 ACF 共识。
候选周期不能直接当一根真实纱线；没有合成补线，也没有使用人工纱距初始化算法。
仅开发集用于选择两种信号形式，留出集只做独立评估。

| 样本 | 原图局部强度：平均纱距误差 | 原图边缘能量：平均纱距误差 |
|---|---:|---:|
| U20261013_01 | 96.00% | 27.85% |
| U20261013_03 | 220.68% | 126.19% |
| U20261013_05 | 87.77% | 176.92% |
| U20261013_02 | 144.72% | 42.79% |
| U20261013_06 | 95.11% | 271.83% |

开发集上选中的方式：edge_energy；其留出集平均误差：157.31180588102657%。
警告：本实验基于普通手机单图且角度来自当前原版算法，并不满足认证 R/T、mm/px、5cm实体框的计量条件。
