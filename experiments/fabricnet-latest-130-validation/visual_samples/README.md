# FabricNET visual inspection subset (6 of 130 images)

Each JPEG is a crop/overlay of the actual recorded algorithm output, never a truth-guided grid.
V063 is direct original engine; FLOAT, SHARED and INDIVIDUAL are isolated 8k
experimental modules run on duplicated single microscope images. No genuine R/T exists.
Actual 130-image output, all failure cases and truth comparisons remain in
Actions runs 39538548889 and 39539100618 respectively.
Original FabricNET photographs: Mine Seçkin, Ahmet Çağdaş Seçkin,
Pinar Demircioglu, Ismail Bogrekci (2023), Sustainability 15(21), 15197.
