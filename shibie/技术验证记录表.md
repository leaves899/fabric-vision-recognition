# Fabric Measurement Engine 后续功能技术验证记录表

## 使用边界

- 当前用于验证算法链路是否可运行、可重复、可解释；不作为正式计量精度验收。
- FabricNET 单图双输入时，必须标记为“伪反射/伪透射 PoC”。
- FabricNET 参数表未提供单张图的视场或 `mm/px`；本轮统一以 `0.0100000 mm/px` 驱动 Gate 和算法链路，所有毫米换算及密度数值均不得用于绝对计量误差比较。
- 所有未运行项保持“未执行”，不得用估计值代替实测结果。

**输入**：`W001.jpg` 至 `W130.jpg`；每张同图双输入为伪反射/伪透射 PoC；`mm_per_px_x=0.0078125`、`mm_per_px_y=0.0083333`；经向映射提示为垂直。

## 结果结论

| 结论项 | 当前状态 | 依据 |
|---|---|---|
| 表观宽度模块已实现 | 已实现，待真实样本验证 | 代码采用“透射中心线 → 反射图法向梯度边缘对 → P10/P50/P90”，不改写密度主链。 |
| 经纱 P10/P50/P90 可输出 | 已验证可输出 | 全量 130 张均输出分位数或明确拒测原因；W042、W088 两方向均通过当前像素 Gate。 |
| 纬纱 P10/P50/P90 可输出 | 已验证可输出 | 全量 130 张均输出分位数或明确拒测原因；W042、W088 两方向均通过当前像素 Gate。 |
| 表观宽度链路技术可行 | 可运行，支持正面图 + 透射图双输入 | 当前标定值下，130 张同图输入验证中 2 张通过 Gate、96 张低置信、32 张拒测；双图可按现有接口接入，失败原因可追溯。 |
| 表观宽度绝对误差已验证 | 不适用（当前阶段） | FabricNET 不提供人工/显微宽度真值。 |
